# 구글 AI vs campus-rag 비교

같은 질문을 구글 검색(AI 개요/AI 모드)과 우리 서비스에 똑같이 던지고, **같은 채점기·같은 정답 체크리스트**로 채점해 어디서 누가 이기는지 확인한다.

## 질문 구성 (`cases.jsonl`, 41개)

| 유형 | 개수 | 확인하려는 것 |
|---|---|---|
| `recent` 최근 공지 | 7 | 2주 안에 올라온 공지. 구글 색인이 늦는 구간 |
| `attachment` 첨부 속 내용 | 8 | 공지 본문엔 없고 HWP/PDF 첨부에만 있는 사실 |
| `semester` 이번 학기 특정 | 6 | 매년 반복되는 공지. 작년 정보와 섞이는지 |
| `dept` 학과 고유 | 2 | 컴퓨터·인공지능공학부 내부 공지 |
| `cohort` 학과·입학년도별 조건 | 10 | 학번·학과·편입 여부에 따라 답이 갈리는 규정 (2026-10-25 추가) |
| `unanswerable` 자료에 없음 | 2 | 모른다고 해야 정답. 지어내는지 확인 |
| `general` 일반 학사 (대조군) | 6 | 회귀 세트에서 가져옴. 구글이 유리할 것으로 예상 |

정답은 DB의 실제 공지·첨부에서 뽑았다(기존 31개는 2026-10-19, `cohort`는 2026-10-25 기준). **날짜가 지나면 정답이 낡으므로** 우리 쪽 실행과 구글 입력을 같은 주 안에 하고, 다음 학기에는 질문을 새로 만든다.

### `cohort` 유형과 정답 미확정 문항

우리한테 유리한 시험지가 되지 않도록 절반은 DB에 답이 없거나 낡았을 수 있는 질문이다.

- `answer_status: "verified"` (001~005): 정답 근거가 `evidence`(제목·URL·날짜)에 있다.
- `answer_status: "unverified"` (006~010): **정답 미확정**. `required_facts`가 비어 있고 채점에서 "미확정"으로 따로 센다(유형별 분모에서 제외). `evidence_note`에 왜 미확정인지, `draft_facts`/`draft_evidence`에 옛 자료에서 찾은 후보 답이 있다 — 정답이 아니라 확인용 참고다.
  - 직접 확인한 뒤 `required_facts`를 채우고 `answer_status`를 `"verified"`로 바꾸면 다음 채점부터 포함된다.

## 구글 답 입력표 (`google_answers.csv`)

`우선순위` 순으로 정렬돼 있다. Excel로 열어서 채운다.

| 열 | 채우는 방법 |
|---|---|
| 우선순위 | 1 = 이번 주 마감·행사(지나면 공지·검색 결과가 바뀜) → 가장 먼저. 2 = 진행 중인 최근 공지, 3 = 이번 학기 지난 일정, 4 = 날짜 무관 |
| 날짜 민감도 / 날짜 메모 | 자동으로 채워져 있음 (마감일 등) |
| 구글 기능 | `AI 개요` 또는 `AI 모드` — 어느 쪽 답을 붙였는지 |
| 구글 답변 | 답변 텍스트 그대로. 안 뜨면 비우고 메모에 "AI 개요 없음" |
| 답변 날짜 | 물어본 날짜 (예: 2026-10-26) |
| 출처 URL 유무 | 구글 답에 출처 링크가 붙어 있었으면 `있음`, 없으면 `없음` |

- 시크릿 창에서 검색해 개인화 영향을 줄인다.
- 질문 앞에 "부경대"를 붙여 검색한다 (우리 서비스는 범위가 이미 정해져 있으므로 공정하게).

## 실행 순서

```powershell
# 1) 우리 서비스 답변 수집 + 채점 (모델 로딩 포함 10분 이상)
.\venv\Scripts\python.exe scripts\compare_google.py run

# 2) 구글 답 입력표 다시 만들기 (질문을 고친 뒤에만. 답이 하나라도 들어 있으면 거부)
.\venv\Scripts\python.exe scripts\compare_google.py template

# 3) google_answers.csv 를 채운 뒤: 구글 답변 채점 + 비교 보고서 생성
.\venv\Scripts\python.exe scripts\compare_google.py report
```

결과는 `eval/results/google_compare_report.md`(git 제외 폴더)에 생긴다.
